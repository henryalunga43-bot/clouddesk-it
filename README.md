# CloudDesk IT

Automated IT Support Ticketing Application
deployed on Microsoft Azure.

## Technologies
- Python Flask
- Microsoft Azure
- Terraform
- Git
- GitHub Actions

## Business Problem
IT teams need a centralized system to create,
track, assign, and resolve support tickets.

## Cloud Engineering Goals
- Provision Azure infrastructure with Terraform
- Automate testing and deployment with GitHub Actions
- Secure cloud resources with Azure identity
- Monitor application performance and errors
- Document infrastructure and recovery procedures
